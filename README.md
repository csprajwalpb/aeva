# Project Aeva

A modern AI assistant powered by Gemini.

## Features

- Real-time AI chat
- Streaming responses
- Chat history
- Markdown rendering
- Code syntax highlighting
- Premium dark UI

## Tech Stack

- Next.js
- TypeScript
- Tailwind CSS
- Gemini API

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
